# Asystence application (app.asystence.com and *.asystence.com workspace hosts).
#
# Everything here is behind authentication, so there is nothing to index. This
# file exists mainly to stop crawlers walking the wildcard subdomain space:
# every workspace host serves this same SPA, and the SPA rewrite answers 200 on
# every path, so an indexable app presents a crawler with an infinite URL set.
#
# Why each crawler is named instead of relying on `User-agent: *`:
# Cloudflare's managed robots.txt prepends its own `User-agent: *` group
# containing `Allow: /`. Crawlers merge groups sharing a user-agent, and an
# Allow beats a Disallow of equal specificity -- so a lone `User-agent: *`
# stanza here is cancelled out before it does anything. A group naming the
# crawler directly is more specific than `*`, and a crawler that finds its own
# name uses that group and ignores the `*` group entirely.
#
# The public marketing site is a separate deployment on the apex domain and has
# its own robots.txt -- this file does not affect its indexing.

Disallow: /
